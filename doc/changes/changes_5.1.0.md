# Transformers Extension 5.1.0, 2026-08-25

Code name: More AI Functions

## Summary

In this release, we added the additional new AI Functions "AI_TRANSLATE" and "AI_ANSWER".
These new UDFs are designed to be easy to use, only requiring minimal input.

For users who need more control over the configuration of their prediction UDFs,
the existing UDFs "AI_TRANSLATE_EXTENDED" and "AI_ANSWER_EXTENDED" are still available.

## Features

* #414: Added AI_TRANSLATE and AI_ANSWER UDFs.
